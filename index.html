About Dose Reconciliation

What this is for

If the sim is out of sync due to missed doses or pump-rate deviations, this dialog brings it back in line. Enter the actual cumulative dose (or volume), pick a strategy, confirm.

Why it works

The PK model is linear time-invariant: two event histories with the same cumulative input converge to the same compartment state once redistribution settles (~30–60 min for propofol). Ce is filtered through the ke0 first-order lag, which smooths the transient further.

The two modes

Single bolus (default). Adds the missing dose as one correction at a chosen time. Use when you can name a specific missed event. Pick the time it happened for an exact reconstruction; case start is a safe fallback (≤1.5 % Ce error at NOW for events older than 90 min).

Spread across case. Adds the missing dose evenly across [0, NOW] as a constant rate offset. Use for sustained rate drift. Reconstructs the intended past exactly. Forward of NOW the sim returns to its un-augmented rate — if the rate mismatch is still active, use Change Rate to fix it forward.

When it's worth correcting

Sustained rate error: Ce % error equals dose % error, regardless of case duration. Doesn't decay.

< 5 %< 5 % — probably not worth fixing

Missed bolus: error fades fast. Even substantial misses become small Ce errors after about an hour.

The reconciling band

An amber-hashed band marks the affected interval. Single-bolus: [insert time, insert time + 3 × intermediate t½]. Spread: [0, NOW + 5 min]. The band and the drug-card pulse clear automatically once case time passes the end.

The purple ghost line

The dashed purple line shows the Ce trajectory before the correction. Clears with the band.
